# P4/P5 Night 文档入口

P4 当前权威入口：

1. `P4_EXPERIMENT_MASTER_RECORD_AND_RULES.md`：全部实验结论、强制流程、必须事项和禁止事项；
2. `P4_EXPERIMENT_LEDGER.csv`：全部可发现的逐运行/逐评价机器总账；
3. `P4_EXPERIMENT_CAMPAIGN_SUMMARY.csv`：逐 campaign 汇总；
4. `P4_EXPERIMENT_DECISION_LEDGER.csv`：逐假设/算法代际结论；
5. `P4_EXPERIMENT_LEDGER_SUMMARY.json`：覆盖率和异常统计。

目录内其他 P4 文档保留为当时的设计、运行或分析快照。它们与总入口冲突时，不再
单独作为当前结论使用。
