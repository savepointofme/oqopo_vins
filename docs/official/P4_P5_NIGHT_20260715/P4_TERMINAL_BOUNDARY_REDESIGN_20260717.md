# P4 末端边界保持型长窗重构

## 问题

当前长窗把所有 FC 位置/速度残差做归一化时间积分，使整个窗口的 FC 总信息恒等于一条量测。释放末帧只得到一个很小的积分权重；绝对姿态因子又放在窗内最低角速度帧。因此求解器优化的是窗口平均拟合，而不是 OpenVINS 实际接收的末端状态。这个模型不能保证长窗保留单行初始化的末端同步信息。

## 新合同

1. 每个视觉关键帧仍拥有独立的 `q/p/v/bg/ba`，相邻状态仍由标准 15 维 IMU 预积分连接。
2. 释放末帧加入完整权重的同步 FC `q/p/v` 绝对边界；它不再被窗口长度或关键帧数量稀释。
3. 其余 FC 数据不再作为重复的独立绝对观测，也不再参与归一化平均。相邻 FC 状态只提供姿态、位置和速度增量约束。
4. 增量噪声按 `sqrt(dt / window_span)` 缩放，使一个固定时间窗被更密或更疏地切分时，总轨迹信息不随采样行数任意变化。
5. FC 因子继续使用鲁棒损失；释放前必须记录末端姿态、位置、速度残差，并以内部门限检查。
6. OpenVINS 只接收末端 `q/p/v/bg/ba` 和 15×15 边缘协方差，不注入初始化图历史状态或 landmark。

## 验收

- 合成一致数据上，长窗末端 q/p/v 残差不得大于末端单行合同允许的量级。
- 将同一时间轨迹切分成更多关键帧，不能因为行数增加而改变 FC 增量总信息量。
- 改变早期 FC 公共平移/速度偏置时，末端绝对边界仍由末端同步行控制。
- fly1、fly2、fly3 使用相同释放时刻、相同相机 stride、相同高度模式和正式 GPS update/start-heading 口径比较；任一短程明显退化即不得进入全程。
- 全程只有三条飞行均不劣于同释放时刻单行对照后才通过。

GPS 只用于离线评价，不进入上述因子、门限或释放逻辑。
