# 单目图像在在线对准中的实际作用

## 先说结论

这套初始化程序使用的是一台相机，不是双目。飞控给出绝对导航位置、速度和方向；板载惯性测量单元给出短时间内的转动与加速度；单目图像负责检查这段时间内的相对运动是否真的和画面变化一致。

图像不是只做“有没有特征”的开关。每个合格的图像观测都会生成像素误差，这些误差及其对初始状态的导数一起进入同一个求解器，直接影响姿态、位置、速度和惯性测量单元零偏的估计与协方差。

## 一幅幅图像怎样变成计算约束

1. 前端在连续图像里寻找角点，并给同一个景物点保持相同的 `feature ID`。例如地面上的一个路口在十幅图中都编号为 123，程序就知道这是同一个真实景物，而不是十个不同的点。

2. 单张单目图像只能得到“景物点位于哪条视线”，不能直接得到距离。飞机向前运动后，同一个景物点在画面中的位置发生变化。程序把多帧相机位置、视线夹角和视差放在一起，三角化出一个只在当前初始化窗口内使用的临时三维点。基线太短、视差太小、解在相机后方或几何条件太差的点会被拒绝。

3. 对于每个保留的临时三维点，程序用当前估计的板载惯性测量单元姿态和位置，加上锁定的 June-12 相机—惯性测量单元固定外参，算出相机应该在哪里、朝向哪里，再预测这个景物点应该落在图像的哪个像素。

4. “预测像素位置减去实际像素位置”就是重投影误差。误差为零表示当前运动解释与图像完全一致；误差增大表示飞控、惯性推算、相机观测或当前初始状态之间存在矛盾。程序对大误差使用稳健损失，避免少量错误跟踪支配整个结果，但不会把错误观测直接当成正确观测。

5. 姿态或位置变化会直接改变相机视线，因此会改变预测像素。速度和陀螺零偏虽然不直接出现在像素投影式里，却会通过惯性预积分改变窗口内各帧的姿态和位置；加速度计零偏会通过速度和位移改变各帧位置。因此这些状态变化也会改变重投影误差。求解器计算这些变化关系，也就是 Jacobian，并和飞控观测、惯性预积分一起求解。

6. 单目图像不能单独给出绝对经纬位置，也不能凭自己确定导航坐标系的绝对方向和尺度。本程序的绝对位置、速度和导航方向仍来自飞控导航状态。图像只约束窗口内真实的相对运动，不能被写成绝对地理定位来源。

7. 因此图像在联合初始化中的实际职责是：检查“飞控给出的运动”和“惯性测量单元积分出来的运动”能否在画面中重现真实的特征移动，并用这种一致性缩小相关初始状态的不确定度。

## 哪些量固定，哪些量参与求解

| 项目 | 本轮动作 |
|---|---|
| June-12 相机—惯性测量单元固定外参 | 锁定，不在线估计，不改成时变 |
| 相机内参和镜头畸变参数 | 锁定 |
| 窗口内相机姿态和位置 | 由飞控、惯性预积分和单目重投影共同约束 |
| 速度、陀螺零偏、加速度计零偏 | 通过惯性预积分与相机位姿链间接受到图像约束 |
| 本次启动的飞控—木板小失准 | 有运动激励时估计；低激励时明确固定到登记先验 |
| 约 7°、4.089° 手工补偿 | 不使用 |
| 转弯时魔术贴柔性补偿 | 不使用 |

## 怎样证明图像真的改变了解算

同一个真实窗口运行三组对照，三组的飞控和板载惯性测量单元数据完全相同：

- V0 原始单目图像：正常加入多帧重投影误差。
- V1 关闭图像：删除全部视觉误差和视觉 Jacobian。只有显式允许时才能以“仅导航可用”启动，绝不能声称完成了视觉联合完整对准。
- V2 扰动单目轨迹：对一半特征加入随时间变化的已知像素扰动。扰动不能被一个固定三维点吸收，因而应提高重投影误差、改变状态或协方差，严重时阻止完整对准。

机器记录包括：跟踪特征数、多帧轨迹数、三角化成功和拒绝的三维点数、视觉误差数量、重投影误差均方根和第 95 百分位、视觉对各状态组的信息贡献，以及消去临时三维点后的视觉信息增量。最终的 `VISUAL_INFLUENCE_AUDIT.csv` 还直接比较有图像与无图像时的状态和协方差差异。
